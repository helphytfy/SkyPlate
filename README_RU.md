# SkyPlate — сервер промокодов (первый релиз)

Это отдельный сервер и закрытая админ-панель. Игроки активируют промокоды через API; новые коды создаются в панели, без изменения HTML игры.

## Что есть
- создание случайного или собственного кода;
- награда — эксклюзивный номер с регионом, редкостью, серией и ценой;
- лимит активаций на код;
- необязательный срок действия;
- отключение и повторное включение кода;
- база SQLite;
- ограничение частоты запросов;
- защита админ API секретным `ADMIN_TOKEN`;
- одна активация одного кода на один ID браузера.

## Важно знать до публикации
1. Чтобы игроки использовали промокоды, сервер должен быть постоянно доступен в интернете.
2. Если игра остаётся локальным HTML-файлом, после публикации сервера нужно указать его URL в HTML-файле. Сам сервер затем можно менять независимо от игры.
3. Сейчас ID игрока хранится в браузере. Игрок может сбросить данные браузера или открыть другой браузер и получить новый ID. Для защиты от этого нужен аккаунт/вход игрока.
4. Этот стартовый сервер выдаёт номера. Включение денежной награды или автомобиля требует интеграции с соответствующей логикой игрового инвентаря.
5. Хостинг должен иметь постоянное хранилище. Если база SQLite находится на временном диске, после перезапуска/деплоя данные могут пропасть.

## Локальный запуск на Windows (для проверки)
Нужен Node.js 22 или новее: https://nodejs.org/

1. Распакуй ZIP.
2. Открой папку `SkyPlate_Promo_Server`.
3. В адресной строке Проводника напиши `cmd` и нажми Enter.
4. Выполни:
   ```bat
   npm install
   ```
5. Сгенерируй длинный секретный токен. Можно временно использовать PowerShell:
   ```powershell
   -join ((1..48 | ForEach-Object { '{0:x}' -f (Get-Random -Maximum 16) }))
   ```
   Сохрани результат в тайне.
6. В том же окне CMD задай переменную:
   ```bat
   set ADMIN_TOKEN=ВСТАВЬ_СЮДА_ДЛИННЫЙ_СЕКРЕТ
   ```
7. Запусти:
   ```bat
   npm start
   ```
8. Открой http://localhost:3000 — появится админ-панель. Адрес API для теста: http://localhost:3000/api/health

## Размещение в интернете (общая схема)
Самый понятный путь — GitHub + хостинг Node.js, поддерживающий постоянный диск.

1. Создай аккаунт на GitHub и новый приватный репозиторий.
2. Загрузи в репозиторий файлы из этой папки, кроме `node_modules` и `skyplate.sqlite`.
3. Создай Web Service на хостинге Node.js и подключи репозиторий.
4. Укажи команду сборки `npm install` и команду запуска `npm start`.
5. Выбери Node 22 или новее.
6. Добавь секретную переменную окружения `ADMIN_TOKEN` (случайная длинная строка; не используй пример и не публикуй её).
7. Подключи постоянный диск и установи `DB_PATH` в путь на этом диске, например `/var/data/skyplate.sqlite`. Убедись, что приложение имеет право записи.
8. После публикации открой `https://АДРЕС-СЕРВЕРА/api/health`. Ответ должен содержать `"ok":true`.
9. Открой `https://АДРЕС-СЕРВЕРА`, вставь URL сервера и `ADMIN_TOKEN` в админ-панель.
10. Создай тестовый код с лимитом 1 и проверь активацию в игре.

Условия бесплатных тарифов и настройка постоянных дисков у хостингов меняются. Перед публикацией проверь, что выбранный тариф сохраняет файлы между перезапусками. Если не сохраняет, подключи PostgreSQL или постоянный диск.

## Подключение к SkyPlate
Файл `SkyPlate_SERVER_READY.html` подготовлен отдельно. После размещения сервера найди в нём строку:
```js
const SKYPLATE_API_BASE = 'https://YOUR-SKYPLATE-SERVER.onrender.com';
```
и замени URL на свой реальный адрес, сохранив кавычки. Затем открой HTML-файл.

**Не раздавай игрокам файл, в котором остались локальные тестовые промокоды.** При переходе на сервер промокоды проверяются сервером, а не встроенным списком.

## API
- `GET /api/health` — проверка сервера.
- `POST /api/redeem` — тело JSON `{ "code": "SKY-...", "playerId": "browser-id" }`.
- `GET /api/admin/codes` — список (требует `Authorization: Bearer ADMIN_TOKEN`).
- `POST /api/admin/codes` — создание (требует токен).
- `POST /api/admin/codes/:id/toggle` — включить/отключить (требует токен).

Перед настоящим публичным запуском рекомендуется добавить аккаунты игроков и резервное копирование базы.
